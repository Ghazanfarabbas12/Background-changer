# Background Changer

A simple React app that lets you change the background color of the screen with a single click.

## Features

- One-click background color change
- Smooth color transition
- Buttons for red, indigo, blue, orange, green, black, and pink
- Built with React 19, Vite, and Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev      # start dev server
npm run build    # production build
npm run lint     # run ESLint
npm run preview  # preview production build
```
